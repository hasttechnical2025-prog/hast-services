Cách hoạt động: Dòng 1 (Ngày · Tìm mã máy/tên khách · Số phiếu) = server — đổi là nạp lại dữ liệu (Số phiếu tra toàn cục, bỏ qua khoảng ngày). 4 phễu trong cột (Loại việc · KTV · HĐ · Trạng thái) = client — thu hẹp ngay danh sách đang thấy, có chip "Đang lọc" + Bỏ lọc cột. Bấm chữ tiêu đề = sắp xếp; bấm phễu = lọc.
